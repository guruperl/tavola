在演示汽车报告和在线投票系统项目之前，请确认你电脑上已安装有一个正常的开发环境。这里介绍如何在Windows 10上安装MySQL数据库，Apache服务器和PHP开发语言。如果你使用linux或者Mac，请参阅相关的软件安装说明。

安装MySQL数据库

下载

  • 进入MySQL官方下载网址：https://dev.mysql.com/downloads/installer/
  • 选择 Windows (x86, 32-bit), MSI Installer第二个文件（近400M大小的那个），点击下载。

安装

  • 执行之前下载的msi后缀文件，开始安装。
  • 建议你只选择两个产品安装：MySQL Server和MySQL Workbench。前者是我们项目所需要的MySQL数据库服务器，后者是连接服务器的终端程序。安装结束后，你还获得一个MySQL Installer（安装管理程序）。你可以在任何时候打开MySQL Installer，重新安装或者修改。
  • 在安装的最后阶段，请设置进入MySQL超级用户root的密码。

启动MySQL数据库

  • 在视窗里搜索 services，即跳出一个 Services的插件，打开，在右边所列执行任务里面，找到”MySQL“服务。右键点击它，选择“属性”，即跳出窗口让你选择电脑打开时，如何启动这个数据库服务器？选择自动启动。
  • 同时确认目前数据库是启动着的。（如果关闭，点击”启动“链接启动它。）

管理数据库和用户

  • Windows10里打开MySQL Workbench。
  • 使用安装结束时设置的root账号和密码，构架一个新的链接终端。 用这个链接终端，链接到本机运行的MySQL服务器上。
  • 这里可浏览和修改已有的数据库，或创建新的数据库（数据库在MySQL表示为一个Schema）。
  • 可以创建针对每一个数据库的管理员账号。赋予他们不同的读写权限。数据库和数据库管理员这快，请参阅相关文档。
  • 你也可以用 phpMyAdmin这个工具管理。请参阅相关文档。

网站服务器软件Apache

下载

  • 进到Apache官网推荐的下载地址： https://www.apachelounge.com/download/
  • 根据你是32位还是64位，下载最新的zip文件，目前64位最新是 httpd-2.4.41-win64-VS16.zip

安装

  • 下载后，解压到到某个指定的目录下面。比如 C:\Apache24。
  • 打开文件管理器，进入这个解压目录下面的conf子目录里。
  • 用notepad或其它编辑器，打开文件 httpd.conf 找到 Define SRVROOT "c:/Apache24"这行。把它设置为你所解压的位置目录。保存修改，退出。

启动网站服务器Apache

  • 以系统管理员身份打开 Windows Powershell（管理员）。
  • 进入解压目录下（C:\Apache24）下的子目录 bin。 
    > cd C:\Apache24\bin
  • 执行这里的 httpd.exe 文件。 
    > ./httpd.exe
    如果没有任何错误跳出，即表明网站服务器在端口80启动了。你可以打开浏览器，查看本地服务器：http://localhost
  • 回到Windows Powershell，用 Ctrl-C关闭正在运行的Apache服务（需要等几十秒）。
  • 执行此命令： 
    > httpd.exe -k install
>
    此Apache服务即被安装到Windows系统里面。
  • 按照MySQL里介绍的方法，打开Services。这时能看到Apach24在服务列表里。打开它的属性，选择电脑启动时自动启动。

安装PHP语言

下载

  • 进入PHP官方下载网址： https://windows.php.net/download/
  • 如果你使用64位视窗，下载最新的 X64 Thread Safe版本（目前是PHP 7.4）。如果你使用32位视窗，下载最新的 X86 Thread Safe版本（目前是PHP 7.4）。 记住，一定是Thread Safe版本，才能和Apache相容。
  • 打开下载的压缩文件，解压到某个目录下面，例如 C:/php-7.4.2。

生成配置文件php.ini

  • 打开文件管理器，进入上面的解压目录（PHP的根安装目录）。 把文件 php.ini-development 拷贝出新文件 php.ini。
  • 打开编辑器，修改此新文件 php.ini 内容。 在760行左右的地方，找到配置参数 extension_dir ext，改为绝对路径 extension_dir C:\php-7.4.2\ext。
  • 在895行左右的地方，找到 extension=mysqli ，修改为 extension=pdo_mysql （注：PHP有两种调用MySQL数据库的方式，我们使用PDO）。
  • 在1056行左右的地方，找到 ; pdo_mysql.default_socket=。去掉前面的; 变成 pdo_mysql.default_socket=。
  • 修改完毕。保存，退出。

加PHP命令到系统路径里

  • 在Windows 10里搜索 Environment，跳出Edit System Environment Variable（即系统环境参数编辑）。
  • 选择”高级“，点页面下部的”环境变量“。
  • 在新的页面下部，找到"路径”，用右键选上.
  • 点击”编辑“。在跳出的页面里，点击”新加“。
  • 在点闪的编辑栏里，输入PHP安装根目录，如 C:\php-7.4.2。保存并退出。

让Apache识别PHP

虽然PHP已经按照完毕，但之前安装的Apache并不识别php文件。这里介绍如何配置。
  • 进入之前解压的Apache目录，如 C:\Apache24。再进入子目录conf。
  • 用编辑器打开 httpd.conf文件。把226行左右的 ServerName设置成 ServerName 127.0.0.1。
  • 在511行左右找到 vhost 的设置行，去掉井号，设为 Include conf/extra/httpd-vhosts.conf。 在520行左右找到 default 的设置行，去掉井号，设为 Include conf/extra/httpd-default.conf
  • 进入子目录extra，找到 httpd-default.conf。编辑器打开，在最下端添加 
    #
LoadModule php7_module "C:/php-7.4.2/php7apache2_4.dll"
<FilesMatch \.php$>
	SetHandler application/x-httpd-php
</FilesMatch>
PHPIniDir "C:/php-7.4.2"
    此后Apache对php结尾的文件即执行PHP程序。根据你的实际安装目录调整其中参数，注意php7apache2_4.dll，php.exe以及php.ini都是在PHP根目录下。

重新构架 http://localhost 网站

假设你开发了一个PHP网站，网页的根目录放在 C:\project-php\www下面。如何在 http://localhost 看到呢？
  • 在 C:\project-php下面创建子目录logs，以存放日志文件。
  • 打开 httpd-vhosts.conf，把原先其它配置去掉（行之前加井号），添加以下内容： 
    #
<VirtualHost *:80>
    ServerAdmin webmaster@localhost
    DocumentRoot "${SRVROOT}/htdocs"
    ErrorLog "logs/error.log"
    CustomLog "logs/access.log" common
</VirtualHost>

<VirtualHost *:80>
    ServerAdmin webmaster@localhost
    DocumentRoot "C:/project-php/www"
    ServerName localhost
<Directory C:/project-php/www>
        Options Indexes MultiViews
        AllowOverride None
        Require all granted
</Directory>
    ErrorLog "C:/project-php/logs/error.log"
    CustomLog "C:/project-php/logs/access.log" common
</VirtualHost>
    保存，退出。
  • 再在Windows 10下打开Services列表，找到Apache24。从新启动它。这时Apache即对你的PHP网站服务了。祝贺，你的PHP构建成功！

构架多个PHP网站（高级课程）

你可以在服务器下运行多个PHP网站。假设第二个网站目录为 C:/project2php/www，在本机上通过网址 http://localhost2 访问。
  • 做为管理员，用编辑器打开 c:\Windows\System32\Drivers\etc\hosts，添加如下行： 
    
127.0.0.1 localhost2
    你即为本地IP添加了一个新的虚拟域名 localhost2 。
  • 用编辑器打开 httpd-vhosts.conf文件，添加（不要删除已有的内容）： 
    #
<VirtualHost *:80>
    ServerAdmin webmaster@localhost
    DocumentRoot "C:/project2php/www"
    ServerName localhost2
<Directory C:/project2php/www>
        Options Indexes MultiViews
        AllowOverride None
        Require all granted
</Directory>
    ErrorLog "C:/project2php/logs/error.log"
    CustomLog "C:/project2php/logs/access.log" common
</VirtualHost>
    保存，退出，再重新启动Apache。第二个网站构建成功！依次类推，你可以 不断添加网站。

安装 composer

PHP近年来的重大进展，就是采用composer解决了过去软件库管理混乱的状态。从此之后，调用外部库变得极其简单和准确。我们的开发也完全准守composer标准。

下载

  • 进入官方网站，下载最新版本： https://getcomposer.org/download/
  • 下载文件为 https://getcomposer.org/Composer-Setup.exe。下载后可执行此文件把它安装在本机上。你即可以在命令行下执行 composer 命令。
  • 务必确认此文件来自上述官方网站的网址！不在其它任何网站下载。
