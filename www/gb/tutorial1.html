通过本演示，你将学习构造一个简单的汽车网站。公共区外网访客能看到各种汽车。后台管理员可登录，添加新汽车，修改或者删除原有汽车。本演示源自于 PHPMaker这个专业PHP开发软件。本解决方案远比它简洁和强大。我们不仅生成网站，还能生成开发手机App所需的API，和基于Vue框架的H5应用。

在进入演示前，务必确认你已经安装好MySQL数据库，网站服务器（如Apache）和PHP编程语言。请参阅安装课程。

你需要申请Tabilet用户账号。我们假设你的用户名为 john。

数据库

项目管理员表格

  • 数据库里自动带有两个表格 login_a和login_a_ip，用于项目管理员登录。前者记录管理员登录名和密码，后者控制登录太多次失败后，如何锁住账号。
  • 系统已自动生成一个管理员，其账号和密码在会员主页可以查到。如果你需要通过Workbench或phpMyAdmin添加管理员，使用如下命令： 
    > INSERT INTO login_a (login, passwd, status, created) VALUES ('LOGIN', SHA1(CONCAT('LOGIN', 'PASSWORD')), 'Yes', NOW());
    其中大写的LOGIN和PASSWORD表示登录名和密码。

汽车表格

  • 点击左边 数据库 链接，进入数据库管理页面。这里看到上述两个表格。（点击表格名称，将打开或关闭表的SQL语句。）
  • 添加新表 的 名称 栏目下，输入我们要建的表格名称 cars。在 SQL表格生成语句 栏目下，输入： 
    (
  `ID` int(11) NOT NULL AUTO_INCREMENT,
  `Trademark` int(11) DEFAULT NULL,
  `Model` int(11) DEFAULT NULL,
  `HP` smallint(6) DEFAULT NULL,
  `Liter` double DEFAULT NULL,
  `Cyl` tinyint(4) DEFAULT NULL,
  `TransmissSpeedCount` tinyint(4) DEFAULT NULL,
  `TransmissAutomatic` varchar(3) DEFAULT NULL,
  `MPG_City` tinyint(4) DEFAULT NULL,
  `MPG_Highway` tinyint(4) DEFAULT NULL,
  `Category` varchar(7) DEFAULT NULL,
  `Description` longtext,
  `Hyperlink` varchar(50) DEFAULT NULL,
  `Price` double DEFAULT NULL,
  `Color` varchar(50) DEFAULT NULL,
  PRIMARY KEY (`ID`)
)
    备注 可设置为空白。点击 提交。

在线开发

开发新分量

创建了表格 cars，你就可以用来开发PHP程序了。在Genelet编程框架里，一个开发项目由多个分量（component）组成。数据库表格和分量通常是一 一对应的。每个分量有自己独立的Namespace，执行对表格的各种Restful指令（action）。你也可以定制指令，编程是可以无限延展的。
  • 点击左边栏目的 项目。此时下面出现 角色 和 分量 两个链接。本演示里，我们不构建新的登录角色。点击 分量。
  • 在 添加新分量 下，名称 栏目里输入 car（此名称不必和表格名相同）。选择表格 里选 cars，分量 car 将对此表执行Resftful指令。
  • 是否作为外网访客缺省分量 和 是否作为管理员的缺省分量 均选上。意思是，访问时，如果不特意指定分量，此分量是否作为缺省。
  • 设置Restful指令执行权限 英文上叫做 Access Control List (ACL)，限制哪个角色可以执行5个Resftful指令里哪些指令。对 外网 这个角色，选上 List 和 Read。 List的意思是观看所有种类的汽车，Read是按照汽车的ID，查看此汽车的细节。
  • 系统管理员可以对所有分量做所以的执行指令。所以管理员角色不另设限制。
  • 点击 提交。完成此次创建。

项目下载

至此，你虽然没有做任何编程工作，但系统已经帮助你完成了此项目的开发！ 你要做工作仅仅是下载自动生成的程序到本地机器上，安装后即可运行。
  • 返回 项目，点击 打包下载软件。

本地安装

确认MySQL，Apache和PHP编程都安装正确。解压下载包到某个文件区，比如 C:\phpmaker。

新建本地数据库

  • 由此下载数据库 https://phpmaker.dev/phpdemo2020.zip

灌入数据库 demo2020

  • 解压，找到文件 demo2020.sql 。用 MySQL Workbench，PhpMyAdmin 或者任何其它工具将 此文件灌进MySQL服务器上。最后生成名为 demo2020 的数据库。
  • 编辑Tabilet生成文件 C:\phpmaker\conf\init.sql，去掉其中的有关表格 cars 的删除和生成语句（此表格和表格数据已经安装好了）后，把其它语句灌进 demo2020。 此操作生成管理员表格和登录的 Procedure 语句。
  • 执行SQL命令： 
    > INSERT INTO login_a (login, passwd, status, created) VALUES ('LOGIN', SHA1(CONCAT('LOGIN', 'PASSWORD')), 'Yes', NOW());
    即在管理员表格 login_a 里安插了一个名为LOGIN，密码为PASSWORD的管理员账号。用于网页上管理员登录。

新建虚拟网站

  • 做为管理员，用编辑器打开 c:\Windows\System32\Drivers\etc\hosts，添加如下行： 
    127.0.0.1 phpmaker
    保存，退出。此行即对本机新加了一个虚拟地址 phpmaker。当浏览网址 http://phpmaker 时，它即在本机上寻找此虚拟域名。
  • 进入你的Apache网站服务器栏目，c:\Apache24\conf\extra，打开>其中 httpd-vhosts.conf文件，添加（不要删除已有的内容。如果你的解压>路径不一样，请做相应修改）： 
    #
<VirtualHost *:80>
    ServerAdmin webmaster@localhost
    DocumentRoot "C:/phpmaker/www"
    ServerName phpmaker
    <Directory C:/phpmaker/www>
        Options Indexes MultiViews
        AllowOverride None
        Require all granted
    <Directory>
    ErrorLog "C:/phpmaker/logs/error.log"
    CustomLog "C:/phpmaker/logs/access.log" common
</VirtualHost>
    保存，退出，再重新启动Apache。此虚拟网站即构建成功。

修改项目配置文件

  • 项目启动时需要的配置参数由一个JSON格式的文件表达，由于运行环境不同， 你需要修改它以便适应本机。用编辑器打开 c:\phpmaker\conf\config.json。
  • 把参数 Document_root，Template，Uploaddir，Filename 里面的 /home/user/tabilet/sandy字符换成你项目根 目录 c:/phpmaker。
  • 把 Server_url 换成当下的虚拟网址 http://phpmaker。
  • 把数据库链接参数换成（假设数据库用户是USER和PASS）： 
    "Db" : ["mysql:host=localhost;dbname=demo2020", "USER", "PASS"],
  • 把登录网站的域名 Roles => a => Domain 换成 
     "Domain"  : "phpmaker",
  • 保存，退出。

安装Genelet和其它软件库

  • 进入 C:\phpmaker，用composer安装所有第三方软件： 
    composer install
  • 继续执行如下命令，以便把下载软件包名，铭记到autoload里 
    composer dump-autoload -o

打开首页

到这一步，你的网站已经安装完毕。请访问此项目首页: http://phpmaker
  • 网页：采用Twig文字模板生成的普通动态网页。
  • API和Vue.js生成的H5应用：基于Restful API，用Vue.js生成的互>动单页网站。此网站稍作修改，即可继续开发为手机H5应用或微信小程序。
