Genelet是新一代的多编程语言框架，提供最新最完整的网站项目开发功能，包括REST API，GraphQL通讯，Vue.js衔接等。开发效率高，安全性周全，能承担高流量后台服务。目前已经在PHP，GO，Java和Perl上实现。

Tabilet提供在线项目开发业务。填写项目需求后，Tabilet自动生成Genelet编程框架初始的PHP程序代码，API数据接口和H5应用网站。你即可在此基础上构建完整软件项目。

功能齐全，开发效率高

  • 自动生成 REST API 和 GraphQL 服务。
  • 自动生成各种登录角色服务，比如基于Oauth2和数据库用户表格的登录服务。
  • 自动生成用于Vue.js单页网站，你可在此基础上快速实现H5小程序或手机应用。
  • 自动生成常用功能，如电子邮件，移动PUSH和SMS等。
  • 自动生成完备的单元检测（Unit Test）和功能检测（Functional Test）环境。

安全和高速流量设计

  • 除通常的角色认证外，Genelet提供ACL（Access Control List， 角色指令许可）， Csrf Token （反钓鱼符）和 Row Level Security （电子签名的数据行认证）。是目前包含有最高安全级别的编程框架。
  • Genelet建立在Horizontally Scalable（水平扩展）概念上。即，当系统内容变得越来越丰富时，其内禀复杂性不是指数级，而只是可控的线性扩展。这对大型项目开发和长期维护非常有帮助。
  • Genelet运行速度快，它采用一套直接调用SQL语言的编程方案 （虽然仍可以衔接第三方ORM）。
  • 极少或者完全不依赖第三方软件。使得项目安装和维护简洁。

多语言

  • Genelet基于一组高效率网站服务协定，可在多种编程语言上实现。目前已经有PHP，GO，Java和Perl，并正移植到Python上去。
  • Genelet允许用多种编程语言开发同一个项目，有助于开发团队的人员继承和新的编程语言的学习。
