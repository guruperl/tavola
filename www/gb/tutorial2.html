  开发软件安装  |   汽车报告  |   在线民调

本演示源自Python编程语言里Django框架的在线民调范例。管理员在后台设计民调问题，每个问题有几种选择，让外网访客在线选择其中一个，即投票。选择的数量统计，即构成一个民调报告。

通过本课程，你将学习如何在线完成此开发项目。把生成的PHP程序，下载到本机或在线云服务上，确认安装好MySQL数据库，网站服务器（如Apache）和PHP编程语言（请参阅安装课程 ）后，即可启动网站了。

你需要申请Tabilet用户账号。假设你账号的用户名为 Sandy。

项目设计

访问者角色

  • 管理员：管理员可以登录后台做民调的管理。
  • 外网访客：无登录要求。在线观看和对民调问题投票。

数据库设计

  • 我们需要两个表格。第一个是民调问题表 poll_question: 
    CREATE TABLE poll_question (
poll_id int NOT NULL auto_increment,
question varchar(255) NOT NULL,
created timestamp,
PRIMARY KEY  (`poll_id`)
);
    其中 question 即问题，poll_id为自动生成的问题序列号，created为填写时间，也是自动生成的。
  • 第二个表格是民调的几种投票选择 poll_choice: 
    CREATE TABLE poll_choice (
choice_id int NOT NULL auto_increment,
poll_id int NOT NULL,
choice varchar(255) NOT NULL,
votes int NOT NULL default '0',
PRIMARY KEY  (choice_id),
KEY poll_id (poll_id)
);
    poll_id即第一个表格的序列号，它是唯一的；choice是民调的答复：votes是此答复的在线投票数。当用户选择一个回答时，投票数即增加1。

管理员工作流程

  • 登录
  • 查看系统里所有的民调
  • 新建一个民调问题
  • 对新建的民调添加几种选项
  • 修改或删除某选项

外网工作流程

  • 发现某民调。为简单起见，我们同时显示目前已有投票计数。
  • 选择几个回答里面的一个提交。
  • 刷新页面后，被选回答的总数增加1。

在线开发

启动项目

  • 登录后，点击 创建新项目和新数据库，启动开发项目。

管理员数据库

  • 项目启动后，系统将自动赋予你一个私有数据库，并自动生成管理员用户表 login_a 和防登录攻击监控表 login_a_ip。
  • 添加或修改管理员通过直接在 login_a 表格里添减数据完成。

民调内容表格

  • 点击左栏 数据库，在 添加新表 下填入 名称 ：poll_question。在 SQL表格生成语句里填入 ： 
    (
poll_id int NOT NULL auto_increment,
question varchar(200) NOT NULL,
pub_date timestamp,
PRIMARY KEY  (`poll_id`)
)
    然后 提交。此表格即生成。
  • 重复上一步，在 添加新表 下填入 名称 ：poll_choice。在 SQL表格生成语句里填入 ： 
    (
choice_id int NOT NULL auto_increment,
poll_id int NOT NULL,
choice varchar(200) NOT NULL,
votes int NOT NULL default '0',
PRIMARY KEY  (choice_id),
KEY poll_id (poll_id)
)
然后 提交。此民调回答表即生成。

开发“民调问题”分量

  • 再次点击左边 项目。这时下面出现 分量 链接。点击此链接，进入分量管理。
  • 每一个数据库表格对应于一个分量。 现在创建新分量。在 名称 里填入 question 表格选为 poll_question，这是民调问题分量。
  • 选上 是否作为外网访客的缺省分量 和 是否作为管理员的缺省分量。
  • 设置Restful指令执行权限 让你选择哪个角色可以执行哪个Restfull指令？管理员总是可以执行所以分量的所有指令，所以这里不再列出管理员这个角色。
  • 除去管理员外，本项目只有 外网 一个角色。选上 Read（外网可以按照ID看某民调） 和 List（民调的罗列）。
  • 提交，此分量即完成。

开发“问题回答”分量

  • 重复 添加新分量。在 名称 里填入 choice 表格选为 poll_choice 建立问题回答分量。
  • 是否作为外网访客的缺省分量 和 是否作为管理员的缺省分量 都不选（因为已经被上一个问题分量选上了）。
  • 设置Restful指令执行权限 让外网选上 List 和 Update。后者用来做投票指令，每投票一次，votes 数目加1。
  • 提交，此分量即完成。

下载

  • 到目前为止，你的项目开始就基本完成了。但存在几个遗留问题，它们不能 用简单的Restful指令实现。我们可以在运行学习如何修改。
  • 回到 项目。点击 打包下载软件。

本地安装

确认MySQL，Apache和PHP编程都安装正确。解压下载包到某个文件区，比如 C:\Django。

新建本地数据库

  • 打开 MySQL Workbench 或 phpMyAdmin, 新建一个 Schema即数据库。名称取为 poll。
  • 把 C:\Django\conf\init.sql 里面的SQL内容，灌进此数据库。此后看到如下四个表格：login_a, login_a_ip, poll_choice, poll_question 和一个名为 proc_sandy_a的Stored Procedure。
  • 执行SQL命令： 
    > INSERT INTO login_a (login, passwd, status, created) VALUES ('LOGIN', SHA1(CONCAT('LOGIN', 'PASSWORD')), 'Yes', NOW());
    即在管理员表格 login_a 里安插了一个名为LOGIN，密码为PASSWORD的管理员账号。
  • 设置一个PHP链接数据库用的数据库用户（它是运行环境的参数之一，属于数据库管理的一部分，这里不再涉及）。我们假设此用户名为USER，密码为PASS。

新建虚拟网站

  • 做为管理员，用编辑器打开 c:\Windows\System32\Drivers\etc\hosts，添加如下行： 
    127.0.0.1 django
    保存，退出。此行即对本机新加了一个虚拟地址 django。当浏览网址 http://django 时，它即在本机上寻找此虚拟域名。
  • 进入你的Apache网站服务器栏目，c:\Apache24\conf\extra，打开其中 httpd-vhosts.conf文件，添加（不要删除已有的内容。如果你的解压路径不一样，请做相应修改）： 
    #

    ServerAdmin webmaster@localhost
    DocumentRoot "C:/django/www"
    ServerName django
    
        Options Indexes MultiViews
        AllowOverride None
        Require all granted
    
    ErrorLog "C:/django/logs/error.log"
    CustomLog "C:/django/logs/access.log" common
    保存，退出，再重新启动Apache。此虚拟网站即构建成功。

修改项目配置文件

  • 项目启动时需要的配置参数由一个JSON格式的文件表达，由于运行环境不同，你需要修改它以便适应本机。用编辑器打开 c:\django\conf\config.json。
  • 把参数 Document_root，Template，Uploaddir，Filename 里面的 /home/user/tabilet/sandy字符换成你项目根目录 c:/django。
  • 把 Server_url 换成当下的虚拟网址 http://django。
  • 把数据库链接参数换成（假设数据库用户是USERh和PASS）： 
    "Db" : ["mysql:host=localhost;dbname=poll", "USER", "PASS"],
  • 把登录网站的域名 Roles => a => Domain 换成 
     "Domain"  : "django",
  • 保存，退出。

安装Genelet和其它软件库

  • 进入 C:\django，用composer即可按照所有第三方软件： 
    composer install
  • 继续执行如下命令，以便把下载软件包名，铭记到autoload里 
    composer dump-autoload -o

打开首页

到这一步，你的网站已经安装完毕。请访问此项目首页: http://django
  • 网页：采用Twig文字模板生成的普通动态网页。
  • API和Vue.js生成的H5应用：基于Restful API，用Vue.js生成的互动单页网站。此网站稍作修改，即可继续开发为手机H5应用或微信小程序。
  • 了解Genelet的基本概念，有助于帮助本例的学习。见 Genelet编程简洁。

后台管理

添加民调问题

  • 点击管理员角色的 a区 链接。
  • 使用之前设置的管理员用户名LOGIN和密码PASSWORD登录。
  • 登录后到达分量 question 的 action=topics 指令页。
  • 目前民调里面没有任何问题。此页为空白页。
  • 把网址里面的指令 action=topics 换为 action=startnew。 
    http://django/app.php/a/html/question?action=startnew
    此页是新添民调表格填写页。
  • 在 Quetion 栏目里输入 你用安卓手机还是苹果手机？，点击 添加。
  • 回到之前的 action=topics 指令页。刷新，新民调即可见到。此问题被自动赋予了一个序列号 poll_id=1。

添加问题选项

  • 把民调问题填写页网址里面的分量换成 choice，即进入民调选项填写页： 
    http://django/app.php/a/html/choice?action=startnew
  • 在 Poll_id 里填写 1，choice 填写 安卓 ，Votes 填 0。 提交。
  • 在 Poll_id 里填写 1，choice 填写 苹果 ，Votes 填 0。 提交。
  • 回到民调选项的LIST页 
    http://django/app.php/a/html/choice?action=topics
    这时 poll_id=1 这个问卷下的两个选项都出现了。

后台登出

  • 登出链接的分量是 logout ： 
    http://django/app.php/a/html/logout
  • 你可以再访问管理员的民调问题页或选项页，这时要求密码输入。表明登出成功。

外网投票

投票问题页

在首页，点击 公共区外网 后的链接，即到达公共区投票问题LIST页。 因为自动生成，此页要做手工做修改。
  • 编程中亦对公共区里问题选择页赋予了LIST功能，所以公众可在 
    http://django/app.php/p/html/choice?action=topics
    看到民调选项。
  • 我们通常在列出民调问题时同时把选项列出来，而不是分割为两个页面。如何实现此功能？
    1. 民调问题和选项是两个表格，目前分别用 quesetion 和 choice 描叙。从分量角度看，就是要求在启动 question 的LIST指令后，对每个记录，再调用 choice 的LIST指令。
    2. 在Genelet编程里，你可以从一个分量调用另一个分量，这个功能称为 nextpage。 进入 C:\django\src\question，打开 component.json，在 current_table 这行之前插入： 
      "nextpages":{
	"topics":[
		{"model":"choice","action":"topics","relate_item":{"poll_id":"poll_id"}}
	]
},
    3. 进入 C:\django\views\p\question，打开 topics.html 文件，在 {% endfor %}<tbody> 行之前加入： 
      <tr>
<td></td><td>
<table>
<tr><th>选项</th><th>目前投票数</th><th></th></tr>{% for one in item.choice_topics %}
<tr><td>{{ one.choice }}</td><td>{{ one.votes }}</td><td><a href="choice?action=update&choice_id={{ one.choice_id }}">投票</a></td></tr>
{% endfor %}</table>
</td><td></td>
</tr>
    4. 回到公共区民调页，此时问题和选项都显示出来了。
  • 公共区不允许 删除 操作（强行点击后即跳出404错误）。可以去掉此链接。

公共投票

  • 在线开发中，投票设为对 choice 做一次 update指令。但目前存在两个问题：
    • 缺省 update 直接修改表 poll_choice 里的 votes 栏，而投票是对它添加 1。
    • 缺省 update 让外网用户修改 poll_choice 里其它栏目，如选项内容字符串（由 update_pars 定义），这不安全。
  • 解决方法是进入 C:\django\src\choice 打开 model.php，改为： 
    <?php
declare (strict_types = 1);
namespace Sandy\Choice;
use Sandy;
class Model extends \Sandy\Model
{
    public function update(...$extra) : ?\Genelet\Gerror {
        if ($this->Get_rolename() == "p") {
            return $this->Do_sql(
"UPDATE poll_choice SET votes=votes+1 WHERE choice_id=?", $this->ARGS["choice_id"]);
        }
        return parent::update(...$extra);
    }
};
    它即取代缺省的 update 指令。当用户是外网用户时，把 votes 值增加1。其它角色（目前即指管理员）仍然采用从Genelet继承来的缺省操作。 其中调用细节我们在Genelet课程里另外介绍。
  • 可以点击 安卓 苹果 后的投票链接。刷新页面后，即看到票数的变化。
